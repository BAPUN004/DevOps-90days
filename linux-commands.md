# Linux Commands - Day 1

## pwd

Print Working Directory.

Displays the current directory.

```bash
pwd
```

---

## ls

Lists files and directories.

```bash
ls
```

---

## ls -l

Displays detailed information.

```bash
ls -l
```

---

## ls -la

Shows all files including hidden files.

```bash
ls -la
```

---

## cd

Changes directory.

```bash
cd Documents
```

```bash
cd ..
```

```bash
cd ~
```

---

## mkdir

Creates a new directory.

```bash
mkdir DevOps90
```

---

## touch

Creates an empty file.

```bash
touch notes.txt
```

---

## cp

Copies files.

```bash
cp notes.txt practice/
```

---

## mv

Moves or renames files.

```bash
mv notes.txt practice/
```

Rename:

```bash
mv oldname.txt newname.txt
```

---

## rm

Deletes files.

```bash
rm notes.txt
```

Delete folder:

```bash
rm -r foldername
```

---

## cat

Displays file contents.

```bash
cat notes.txt
```
