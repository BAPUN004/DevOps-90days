# Linux Interview Questions - Day 1

## 1. What is Linux?

Linux is an open-source operating system based on the Unix architecture. It is widely used for servers, cloud computing, and DevOps because it is stable, secure, and customizable.

---

## 2. Difference between Linux and Ubuntu?

Linux is the operating system kernel.

Ubuntu is a Linux distribution built using the Linux kernel.

---

## 3. What is the root directory?

The root directory is represented by "/".

It is the top-level directory from which every other directory starts.

---

## 4. What does pwd do?

pwd stands for Print Working Directory.

It displays the current location in the file system.

---

## 5. Difference between cp and mv?

cp copies files.

mv moves files or renames them.

---

## 6. What is ls -la?

It lists all files including hidden files along with detailed information.

---

## 7. What is /home?

Stores personal files for users.

---

## 8. What is /etc?

Stores system configuration files.

---

## 9. Why is Linux preferred in DevOps?

- Open Source
- Stable
- Secure
- Lightweight
- Excellent command-line tools
- Used by cloud providers
- Most DevOps tools are designed for Linux

---

## 10. What command is used to find files?

find

Example:

```bash
find . -name "*.txt"
```
